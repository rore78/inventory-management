Architecture overview

Factory Inventory Management System

A full-stack demo app: a Vue 3 single-page app talks to a FastAPI service over JSON/HTTP. There is no database. All data comes from JSON files that are loaded into memory when the server starts and filtered per request.

System architecture

Three layers in two processes: the Vite dev server (port 3000) serves the client, and Uvicorn (port 8001) runs the API.

Data flow: changing a filter

What happens when a user picks, say, Warehouse "Tokyo" and Period "Q3-2025" on the Dashboard.

  1. User changes a filter FilterBar.vue

    The select writes to a ref in useFilters(). These refs are defined at module level, so every view shares the same filter state.

  2. View reacts views/*.vue

    The active view watches the filter refs and calls getCurrentFilters(). That maps Time Period to the API's month parameter.

  3. Request is built api.js

    Any value equal to 'all' is dropped. The request becomes GET /api/dashboard/summary?warehouse=Tokyo&month=Q3-2025.

  4. Server filters in memory main.py

    apply_filters() matches the warehouse exactly and the category and status case-insensitively. filter_by_month() expands Q3-2025 to 2025-07..09 and matches it against order_date.

  5. Aggregate and validate main.py

    Totals are computed for that request. List endpoints are serialised through their Pydantic response_model.

  6. Render views/*.vue

    The response goes into refs. Computed properties build the KPIs, tables and SVG charts, with currency and labels from useI18n().

Things to keep in mind

  • Inventory has no time dimension, so the period filter does not affect it.
  • The Dashboard backlog count ignores all filters.
  • The language (en/ja) is saved in localStorage and also switches the currency (USD/JPY).

Known gaps

Places where the client and server do not line up yet.

Endpoints the frontend calls but the backend lacks

  • /api/tasks: App.vue reads, creates, deletes and toggles tasks through it.
  • /api/purchase-orders: api.js defines create and lookup calls. The PurchaseOrder model and data file already exist.

Hard-coded assumptions

  • The quarter filter and quarterly report only know 2025.
  • The API base URL is fixed to localhost:8001 in two places (api.js and Reports.vue). There is no Vite proxy and no environment variable for it.
  • There is no authentication, and CORS allows all origins. This setup is for local demos only.
